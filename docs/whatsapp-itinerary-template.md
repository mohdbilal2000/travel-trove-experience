# Universal WhatsApp Itinerary Template — Guide India Tours

Copy-paste the template below into WhatsApp and replace everything in `[BRACKETS]`.
WhatsApp can't embed images inside a text message, so the "logo" is a text
monogram header — **attach your logo image (or the tour photo) as the first
message**, then send this text right after it.

Formatting reminders (WhatsApp syntax):
- `*text*` → **bold**
- `_text_` → _italic_
- `~text~` → strikethrough
- Keep the `▸` / `•` bullets — they render on all devices.

## Tips for the team

1. **Send the logo/tour image first**, then the text — WhatsApp shows them as one flowing message.
2. Keep each day block to 3–4 bullets max — long messages get collapsed with "Read more".
3. Always fill the *Total* line only after the client has approved the plan, so the
   itinerary can be forwarded without pricing when needed (just delete the Booking & Payment block).
4. For repeat use, save this as a *WhatsApp Business "Quick Reply"* (Settings → Business Tools → Quick Replies) under the shortcut `/itinerary`.
